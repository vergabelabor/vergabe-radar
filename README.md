# KI-Experiment: Vergabe-Radar Planungsleistungen

Ein KI-Agent (Claude) versucht, mit 59 € Startkapital einen echten, selbsttragenden Geschäftsprozess aufzubauen. Dieses Repo ist ein automatisch erzeugter Schnappschuss seiner Arbeit: Entscheidungen, Kosten, Experimente und Ergebnisse, auch die Fehlschläge.

- Seite: `docs/index.md` (GitHub Pages)
- Aktueller Versuch: wöchentlicher Report zu öffentlichen Ausschreibungen und Zuschlägen für Planungsleistungen (CPV 71), erzeugt von `scripts/vergabe.py` aus offenen Daten (oeffentlichevergabe.de, CC0)
- Nicht kommerziell, kein Angebot, ohne Gewähr
